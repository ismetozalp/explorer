# Explorer Markdown Preview Sample

This file exercises Explorer's **rendered Markdown** preview path. It has
headings, a list, a code block, a table, and a link.

## Features exercised

- Headings (this section and the one above)
- An unordered list (these three bullets)
- *Italic* and **bold** text, and `inline code`
- A fenced code block
- A table
- A link

## A short code block

```python
def greet(name: str) -> str:
    return f"Hello, {name}! This is a Markdown code block."

print(greet("Explorer"))
```
